 ## Отзывы к фильмам

 Тут каждый желающий может оставить отзыв к выдуманному фильму

 ## Как запустить

 1. Клонировать репозиторий
 2. Настроить виртуальное окружение (venv)
 3. Установить зависимости из файла requirements.txt
 4. Создать файл .env и заполнить его по образцу:
 ```commandline
 DATABASE_URI=sqlite3:///films.sqlite3
 SECRET_KEY=YOUR_SECRET_KEY
 ```
 5. Выполнить команду `flask run`
